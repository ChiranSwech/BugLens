# Redesign HTML Bug Report Template

This plan outlines the redesign of the HTML Bug Report template generated by the BugBuddy extension. The goal is to transform the single-column linear layout into a professional, enterprise-grade interactive document that effectively organizes the wealth of diagnostic data now captured (Network, Console, Storage Snapshots).

## Proposed Changes

### [MODIFY] SidePanel.tsx
The `exportAsHTML` function inside `packages/extension/src/sidepanel/SidePanel.tsx` will be completely overhauled.

#### 1. Layout & Navigation (Enterprise Layout)
- **Sticky Sidebar:** Implement a left-hand navigation sidebar with jump links to key sections: `Summary`, `Steps to Reproduce`, `Network Logs`, `Console Logs`, and `Application Storage`.
- **Main Content Area:** A scrollable right-hand panel containing the actual data, styled with maximum readability.
- **Responsive Design:** On smaller screens or when printed, the sidebar will collapse or move to the top.

#### 2. Aesthetic & Typography Upgrades
- **Premium Dark Mode:** Use a sophisticated dark theme (`#0f172a` backgrounds, `#1e293b` panels, `#334155` borders) with subtle gradients and glassmorphism elements to feel modern and premium.
- **Typography:** Enforce high-quality typography (Inter or Plus Jakarta Sans) with clear visual hierarchy, utilizing muted text colors for metadata and bright colors for critical info.

#### 3. Interactive Data Presentation
- **Storage Snapshot Inspector:** Convert the current raw `<pre>` block into a styled, syntax-highlighted-like JSON container.
- **Expandable Details:** Utilize native HTML `<details>` and `<summary>` tags for Network Response bodies and complex Console objects. This prevents massive layout bloat while keeping data immediately accessible.
- **Status Indicators:** Use beautiful, styled badges for Network status codes (e.g., green for 200, red for 4xx/5xx) and Console log levels (Error vs Warning).

#### 4. Print-Optimized
- Ensure that the `@media print` CSS cleanly strips the sidebar, expands all `<details>` tags, and sets page breaks appropriately for PDF export.
